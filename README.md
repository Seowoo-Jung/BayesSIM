# BayesSIM

This package is for fitting Bayesian single-index model based on
`nimble` R package.

<!-- badges: start -->

<!-- badges: end -->

`BayesSIM` is an R package designed to facilitate Bayesian inference for
single-index models. It provides a user-friendly interface for model
fitting, visualization, convergence diagnostics, and prediction. The
package is intended to be accessible to users with little experience in
`nimble`, while also offering sufficient flexibility for advanced users
who wish to customize the model specification and inference procedure.

## Installation

You can install released version of `BayesSIM` from CRAN:

``` r
install.packages("BayesSIM")
```

Alternatively, you can install the development version from CRAN like
so:

``` r
# install.packages("devtools")
devtools::install_github("Seowoo-Jung/BayesSIM")
```
